How it works

1

Install & launch

Install Leakling from the Overwolf store. Launch it alongside Valorant — it sits quietly in the background.

2

Die in-game

The overlay auto-appears on death with a 6-second timer. Tells why you died: Crosshair, Overpeek, No utility, Bad timing, Poor trade, or Others.

3

Review between queues

Switch to the desktop hub to see your cause breakdown, recent tags, and match history. Watch patterns emerge.

4

Set a focus, improve

Each match auto-suggests a focus area. Work on it next game. Your leak profile gets more precise every session.

Your data stays yours

🔒 Local analysis only

Leakling uses a lightweight screen capture to live-review the match as you play. It processes everything on your machine and discards it the moment each frame is analyzed.

🚫 No recording

Nothing is recorded or saved. No clips, no replays, no cloud uploads. Only anonymous death-cause tags and match stats stay on your device.

🖥️ No interference

Leakling reads only what's on screen at the OS level — the same way streaming software does. It never touches the game process or memory.

Frequently asked questions

Is Leakling a stat tracker?

No. Leakling is an improvement tool, not a stat tracker. It doesn't show KD, ACS, or headshot percentage. It focuses on one thing: the tactical mistakes behind your deaths and how to fix them.

Will this get me banned by Vanguard?

Leakling never touches the Valorant game process or memory. It only reads what's on your screen at the operating-system level — the same approach used by streaming and recording software. Your gameplay, account, and system are left completely untouched.

Does Leakling affect my FPS or game performance?

Leakling is built to be lightweight. It uses a screen capture to live-review your gameplay while you play, and keeps resource usage to a minimum. It only reviews at full speed while you're actually in a match, and throttles down to near-zero otherwise.

Does Leakling record or upload my gameplay?

No. Nothing is recorded, saved, or uploaded. Leakling live-reviews your screen in real time on your machine and discards each frame immediately after analysis. Only anonymous death-cause tags and match summaries stay on your device.

Do I need any special hardware to use Leakling?

No. Leakling runs on any Windows PC that can run Valorant. It's designed to work on CPU alone, with no dedicated GPU or special setup required.

Does it work with multiple monitors?

Yes. Leakling automatically detects which display Valorant is running on and captures from the correct screen, even in a multi-monitor setup.

Does Leakling need the Valorant API or developer access?

No. Leakling works entirely through local screen analysis and doesn't require the Riot Games API. Your Riot account is never accessed.

How does the AI detect my flaws?

Leakling uses a deep-learning model trained on gameplay to spot the moments behind each death — like crosshair placement, positioning, or decision-making. It compares each situation to how the same situation might play out flawlessly, then suggests one focus area to work on next.

Is Leakling free?

Yes — Leakling is free. A demo is available now, and the Overwolf integration is coming soon. Sign up for the waitlist below and we'll keep you posted.

Can I use Leakling with other games?

Leakling is built specifically for Valorant and its game mechanics. Support for other games may come later, but for now the focus is on making Valorant improvement as good as it can be.
